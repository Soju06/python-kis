### `real`/`virtual` → `live`/`paper` — 이슈 미등록

논의만 하고 결론이 나지 않았습니다.

| | 근거 |
|---|---|
| 유지 | `virtual` 은 KIS 도메인(`openapi**vts**`)에서 온 이름 |
| 변경 | `real` 은 벤더 표기가 아니고 `Realtime*` **236곳**과 충돌. 영어권 표준은 `live`/`paper` |
| 시점 | 사용자가 사실상 0명인 **지금이 가장 쌈** |
| **위험** | `config.yaml` 키 변경 — 안 고치면 **조용히 실전 계좌로 붙을 수 있음** |
