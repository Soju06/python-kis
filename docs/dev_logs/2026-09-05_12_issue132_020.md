## 밟은 함정

살아 있는 문서의 `현재` 줄에 `0.1.x` 를 두면 태그를 찍는 순간
`test_docs_current_version` 이 실패합니다. `0.x` 로 두면 0.1 과 0.2
둘 다 통과합니다. 같은 줄에 `1.0.0` 을 적으면 그 숫자도 잡힙니다.

`uv pip install --index-url TestPyPI --extra-index-url PyPI` 는
패키지가 PyPI 에 이미 있으면 TestPyPI 의 `0.2.0rc1` 을 안 봅니다.
확인용으로 `--index-strategy unsafe-best-match` 가 필요했습니다.

CHANGELOG 만 있는 PR 본문에 `Closes #132` 를 쓰면 태그 전에 이슈가
닫힙니다. 게시는 이슈 완료 기준입니다.

태그 없는 `uv build` 는 `0.1.0.post1.devN+g…` 가 됩니다. PyPI 가
거부하므로 태그가 찍힌 커밋에서만 올립니다. `v0.2.0-rc1` 붙임표는
쓰지 않았습니다.
