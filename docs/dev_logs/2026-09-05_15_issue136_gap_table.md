## 밟은 함정

표의 **예제** 칸은 `examples/` 파일입니다. USER_GUIDE 코드 조각은
문서입니다. `hello_world.py` 는 `create_client` 를 부르지 않습니다.
인증은 `get_quote.py` / QUICKSTART 가 가르칩니다.

`SimpleKIS` 중급 예제는 `stock.chart()` / `orderbook()` 을 커버하지
않습니다.

장운영 API 는 `kis.trading_hours(market)` 입니다. USER_GUIDE FAQ 는
인자를 빼고 `is_market_open` 을 읽고, `docs/FAQ.md` 는
`stock.trading_hours()` · `is_open_now` 를 읽습니다. 둘 다 코드에
없습니다. TR 을 새로 열 칸이 아닙니다.

USER_GUIDE 의 `sellable()` / `profit()` / `daily_executions()` 는
코드의 `orderable` / `profits()` / `daily_orders()` 와 이름이
다릅니다. 후속은 가이드 이름이지 새 TR 이 아닙니다.

살아 있는 문서 검사기는 `docs/` 와 루트만 봅니다. 예제 안내의
`1.0.0` 은 거기로 안 잡힙니다.

결함을 되넣을 때 `git checkout` 으로 복원하지 않습니다. 사본에서
되돌렸습니다. 바닥을 다시 붙이면 검사가 실패합니다.
