## #106 — 겹치는지 세지 않고 **틀렸는지** 봤습니다

이슈는 *"두 문서가 겹치는지 먼저 확인"* 하라고 합니다. 제목 구조를 대 보니
8절 중 5절이 겹쳤습니다. 그런데 그것보다 결정적인 것이 나왔습니다.

```text
13행  paper=True,                            ← #78 검사기가 코드펜스만 고침
19행  - `virtual=True`: 실제 서버 접근 없이…    ← 바로 아래 설명은 옛 이름 그대로
181행 from pykis import PyKis, KisAuth        ← 포크 이전 패키지명
254행 - KisAuth.virtual 필드 추가              ← 커밋 메시지 예시
```

**같은 절 안에서 코드와 설명이 서로 어긋납니다.** `#78` 의 검사기는 코드펜스만
읽으므로, 그 코드를 설명하는 산문이 코드에서 멀어진 것을 못 봅니다.

`KisAuth` 의 실제 인자는 `['id','appkey','secretkey','account','paper']` 입니다.

> **겹침 여부보다 "지금 따라 하면 되는가"가 먼저입니다.** 겹치지 않는 부분이
> 있어도 그 부분이 틀렸으면 살릴 이유가 없습니다.

다만 이 문서에만 있던 **성능 테스트 작성 규칙**(벤치마크·메모리 프로파일링)은
정본에 없습니다. `tests/performance/` 는 지금도 있습니다. 그 사실을 동결
안내에 적었습니다 — 채울지는 별도로 정합니다.
