# 2026-09-05 - #127 Python 3.14 끝단 개발 일지

## 작업 내용

이슈 [#127](https://github.com/visualmoney/vm-stock-kis/issues/127).
분류기에 3.14 를 넣고 CI 끝단을 3.10 / 3.14 로 올렸습니다. 중간
버전은 늘리지 않았습니다. `requires-python = ">=3.10"` 은 그대로입니다.

정책 10.1 은 CI 가 3.10–3.13 전부를 돈다고 적고 있었습니다. 하한과
분류기 최신만 가리키게 고쳤습니다. 표도 버전 숫자를 박지 않습니다.

끝단은 `ci.yml` 과 분류기에서 읽습니다. 검사 파일에 3.14 를 정본으로
박지 않습니다. 낡은 끝단은 `#127` 이전의 `3.13` 문자열만 결함으로
먹입니다.

## 밟은 함정

`uv run --python 3.14` 가 프로젝트 `.venv` 를 3.14 로 갈아엎습니다.
`.python-version` 은 3.10 입니다. 확인이 끝나면
`uv venv --python 3.10 --clear` 뒤에 `uv sync --locked --group dev`
로 되돌립니다. `--clear` 없이 `uv venv --python 3.10` 은 이미
있는 환경을 거부합니다.

정책에 중간 버전을 나열하면 CI 는 끝단만 도는데도 문서가 거짓말이
됩니다. "최대 지원" 도 같은 함정입니다.

결함을 되넣을 때 `git checkout` 으로 복원하지 않습니다. 사본에서
되돌렸습니다.

실패합니다. 3.14 에서 기존과 같은 단위 검사 집합도 통과했습니다.
