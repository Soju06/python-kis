## 밟은 함정

경로만 고치면 틀린 스키마가 최신처럼 보입니다. `#95` 가 이 노트북을
뺀 이유이고, `#70` 이 `virtual` → `paper` 로 이름만 바꾸며 밟은
것과 같습니다. 그래서 이름 검사(`config.yaml`) 외에 YAML 키 형태
`id: "YOUR_ID"` 를 따로 봅니다. `KisAuth(id="…")` 와 구별됩니다.

되돌리기 확인에 `python` 을 치면 WSL 이 Windows `pyenv` 심을 탑니다.
주입이 안 된 채로 검사가 통과했습니다. `uv run python` 으로 다시
넣어서 둘 다 실패하는 것을 봤습니다.

복구는 `git checkout` 이 아니라 미리 뜬 사본입니다. `#95` 일지가
커밋 안 된 검사 파일을 `git checkout` 으로 날린 것과 같은 자리입니다.

실행되지는 않습니다.
