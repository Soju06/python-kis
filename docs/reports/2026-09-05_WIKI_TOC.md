## 갈래

| | 하는 일 | 검사 | 채택 |
|---|---|---|---|
| **현행** | 위키는 포인터. 목차·예제는 저장소 | README·가이드·예제를 CI 가 봄 | **예** |
| 위키에 본문 복제 | USER_GUIDE 를 Tutorial 에 옮김 | 위키 git 은 CI 밖. `#104` 와 같음 | 아니오 |
| 위키에 링크 목차만 | 1.1–4.4 와 저장소 URL | 헤딩이 바뀌면 위키만 404 | 아니오 |

세 번째 갈래는 본문보다 얇지만, **틀린 안내가 없는 것보다 나쁩니다.**
위키 앵커를 README 에 되돌리면 `#135` 검사가 막습니다
(`wiki/Tutorial#`).

## 함정

위키는 저장소 밖 git 입니다. `gh` 를 위키 클론 cwd 에서 치면 다른
저장소로 갑니다 (`#135`).

`USER_GUIDE` 목차는 아직 10개 큰 절입니다. Tutorial 1.1–4.4 알갱이는
`examples/01_basic/` 파일 목록이 대신 가리킵니다. 그 알갱이를
가이드 목차에 넣는 일은 **저장소 문서** 이슈이지 위키 이슈가 아닙니다.
이 결정이 그 일을 열지 않습니다.

`#30` 게이트를 당기지 않습니다.
